# Prashant Singh — Personal Brand Website & AI Agent

A modern personal brand website with an embedded AI assistant ("Ask Prashant") built with Next.js 16, React 19, Tailwind CSS, and Google Gemini API (`gemini-2.5-flash`).

## 🚀 Features

- **Hero & Intro:** Dynamic code terminal, live interactive stats counter, and prominent Academic Excellence Award banner.
- **About:** Overview of background as 1st-year B.Tech CSE student at VGU × NIAT (GRIT Cohort 2024–2028).
- **Skills & Tech Stack:** Categorized skills across Languages, Web Dev, Applied AI, and Tools.
- **Hackathons Timeline:** Interactive timeline showcasing hackathons and awards.
- **Live Projects:** Direct links to live deployed applications (*The DeskLaunch Co.* & *Lead to Cash MVP*).
- **Certifications Directory:** Searchable catalog of 11 certifications.
- **Ask Prashant AI Agent:** Embedded AI chat assistant with real data grounding and rate-limiting.
- **Contact:** One-click connect via Email, LinkedIn, WhatsApp, Instagram, and YouTube.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** Tailwind CSS
- **AI Integration:** Google Gemini API (`gemini-2.5-flash`)
- **Deployment:** Vercel

## ⚙️ Setup & Environment Variables

1. Clone the repository:
   ```bash
   git clone https://github.com/prashantsingh85699-gif/personal-brand-website.git
   cd personal-brand-website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create `.env.local` and add your Gemini API Key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. Run locally:
   ```bash
   npm run dev
   ```
